## Selected work

### ⚡ [WARP](https://github.com/Its-Rajdip-Shah/WARP)
**A macOS workflow context manager built with Hammerspoon and Lua.**

Restores application-specific work contexts across VS Code, Safari, Finder and other tools. The interesting part isn't the radial menu — it's the systems work underneath it: resource identity, asynchronous OS state, cancellation, failure isolation, state restoration, verification and safe fallbacks.

**Lua · macOS Accessibility · State Machines · Automation · Testing**

---

### 🧩 [ARC Scheduler Arena](https://github.com/Its-Rajdip-Shah/ARC-Scheduler-Arena)
**Exploring scheduler architecture and resource-management systems.**

A project focused on explicit domain contracts, scheduler authority boundaries and the foundations needed to reason about scheduling behaviour before optimisation.

**Scheduling · Systems Design · Resource Management**

---

### 🍜 [Meal Planner](https://github.com/Its-Rajdip-Shah/Meal-Planner)
**A full-stack biweekly meal planning and grocery system built for actual use.**

A React application backed by Supabase/Postgres with authentication, persistent meal data and grocery planning — an example of the other side of how I like to build: identify a problem, make the product, deploy it and use it.

**React · Vite · Supabase · PostgreSQL · Full Stack**
